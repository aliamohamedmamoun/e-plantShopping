# e-plantShopping

## Project Overview

**e-plantShopping** is a plant shopping web application built with React and Vite. It provides a user-friendly interface for browsing and shopping for plants online. The application aims to make it easy for users to explore different plants and enjoy a simple, convenient online plant shopping experience.

## Features

- Browse and explore plants.
- View plant shopping information.


## Technologies Used

- **React** – Building the user interface.
- **Vite** – Development server and build tool.
- **JavaScript** – Application logic.
